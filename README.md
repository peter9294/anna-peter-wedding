# Anna & Peter — Wedding Invitation

Static one-page invitation (EN / ไทย) for 8 November 2026, hosted on GitHub Pages.

- `index.html`, `style.css`, `app.js`: the page (no build step)
- `config.js`: Google Form settings for the RSVP form
- `photos/p0.jpg` … `photos/p10.jpg`: hero, schedule and gallery photos

Preview locally: `python3 -m http.server` → http://localhost:8000
Add `?lang=th` to open in Thai.
